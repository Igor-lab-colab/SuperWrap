# SuperWrap
SuperWrap — серверный плагин для фреймворка Oxide/Carbon, расширяющий стандартный геймплей Rust. Он добавляет механику «Супер оберточной бумаги», позволяющую упаковывать до 20 любых предметов (включая оружие, кастомные скины и вложенный лут) в один компактный кейс-подарок с последующей безопасной распаковкой и логированием.

Команда для выдачи игроку, супер оберточную бумагу:
superwrap.give %STEAMID% 1
